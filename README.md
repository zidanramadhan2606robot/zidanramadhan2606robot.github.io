# M Zidan Ramadhan — Portfolio

Personal portfolio website for **M Zidan Ramadhan**, Web & Mobile Developer and Management Informatics student at Politeknik Negeri Sriwijaya, Palembang.

Live at [zidanramadhan2606robot.github.io](https://zidanramadhan2606robot.github.io/).

## Stack

- **Framework:** React 19 + TypeScript + Vite 6
- **Styling & Typography:** Tailwind CSS v4, custom `--box-size` 8-column editorial grid, self-hosted `Editorial New`, `Neue Montreal`, and `Supply Mono`
- **Motion:** Lenis smooth scroll + GSAP `ScrollTrigger` & `SplitText`
- **Deployment:** GitHub Pages via `.github/workflows/deploy.yml`

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Production Build

```bash
npm run build
npm run preview
```

## Content

Personal links, featured case studies, project archive, and stack data live in `src/data/portfolioData.ts`.
